# ForeignTrade Engineering Skill

## مأموریت
توسعه سامانه بازرگانی خارجی با اولویت صحت دامنه، امنیت داده، قابلیت ردیابی و نگهداری‌پذیری.

## پیش از تغییر
- AGENTS.md، پروپوزال v1.1 و ADRهای مرتبط را بخوان.
- مدل و کد فعلی را بررسی کن؛ فرض نکن چیزی وجود دارد.
- مسیر داده از API تا Domain و SQL را دنبال کن.
- Tenant و Company را تفکیک کن؛ دوره عملیاتی را از دوره حسابداری جدا نگه دار.

## قواعد
- تست قبل از منطق جدید.
- مجوزدهی صریح در سرور؛ Global Query Filter تنها دفاع تکمیلی.
- گزارش چندشرکتی فقط بر اساس شرکت‌های مجاز سرور.
- فایل‌ها دارای کنترل نوع/اندازه/هش/نسخه و مجوز دسترسی باشند.
- State machine و audit برای گردش‌های حساس.
- مبالغ با decimal و ارز/واحد صریح؛ تاریخ ذخیره‌شده UTC.
- RTL و asset محلی.
- بدون secret، بدون تغییر مخرب DB، بدون وابستگی بی‌دلیل.

## پایان کار
Diff را بازبینی کن؛ تست واقعی را اجرا کن؛ تغییرات مستندات را ثبت کن؛ وضعیت و ریسک را دقیق و فارسی گزارش بده.
