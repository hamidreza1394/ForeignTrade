# فهرست مستندات

- `ARCHITECTURE.md`: معماری هدف و مرزبندی ماژول‌ها
- `DECISIONS.md`: تصمیم‌های معماری ثبت‌شده
- `SECURITY.md`: مدل تهدید، احراز هویت و جداسازی داده
- `DATA_MODEL.md`: مفاهیم Tenant، Company، عضویت و دوره عملیاتی
- `AUTH_AND_WORKSPACE.md`: ورود، انتخاب شرکت/دوره و نمایش دوره‌ها
- `DEVELOPMENT.md`: راه‌اندازی و گردش توسعه
- `TESTING.md`: راهبرد تست
- `UI_STANDARDS.md`: استاندارد رابط فارسی RTL
- `SKILLS_AND_AGENTS.md`: کیت مهارت‌ها و عامل‌ها
- `ROADMAP.md`: مراحل اجرا و وضعیت کار
- `SOURCE_PROVENANCE.md`: منشأ کدهای اقتباسی از فرانو

مبنای نیازمندی‌های دامنه، پروپوزال «واحد نرم‌افزار بازرگانی ابری واردات — نسخه ۱.۱» است. اگر جزئیاتی در پروپوزال نیامده باشد، به‌عنوان تصمیم یا فرض جدید علامت‌گذاری می‌شود.
