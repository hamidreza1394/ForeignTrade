# استاندارد رابط کاربری

- زبان فارسی و جهت RTL در تمام صفحات.
- متن، اعداد، تاریخ و شناسه‌های لاتین در صورت نیاز با `bdi`/جهت مناسب نمایش داده شوند.
- فرم‌ها دارای label، پیام خطای قابل فهم، focus state، keyboard navigation و حالت pending باشند.
- انتخاب شرکت و دوره با فهرست‌های قابل جست‌وجو، وضعیت روشن و توضیح دلیل عدم امکان انتخاب.
- موبایل: کارت‌های عمودی؛ دسکتاپ: جدول/چیدمان دو ستونه در صورت مفید بودن.
- از شلوغی بصری، رنگ به‌عنوان تنها نشانگر وضعیت و انیمیشن غیرضروری پرهیز شود.
- فونت، آیکون، CSS و JS در پروژه بسته‌بندی شوند؛ هیچ CDN زمان اجرا.
- Tailwind و shadcn/ui با نسخه ثبت‌شده در پروژه؛ کامپوننت‌های اختصاصی باید مستند و قابل تست باشند.
