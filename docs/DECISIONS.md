# تصمیم‌های معماری (ADR Index)

## DFT-001 — مخزن و محصول مستقل
**وضعیت: Accepted.** ForeignTrade در مخزن مستقل توسعه می‌یابد؛ از فرانو فقط کد و الگوهای مشترکِ بازبینی‌شده اقتباس می‌شود. چرخه انتشار و دامنه تجاری مستقل می‌ماند.

## DFT-002 — Modular Monolith
**وضعیت: Accepted.** برنامه با معماری ماژولار یکپارچه آغاز می‌شود. Microservices فقط با نیاز مستقل و شواهد عملیاتی بررسی می‌شود.

## DFT-003 — Tenant و Company دو مفهوم مستقل
**وضعیت: Accepted.** Tenant مرز مشتری/داده و Company شرکت عملیاتی است. هر Tenant می‌تواند چند Company داشته باشد. دسترسی بین Tenantها ممنوع است؛ دسترسی چندشرکتی داخل Tenant نیز فقط بر اساس عضویت/مجوز.

## DFT-004 — پایگاه داده مشترک با جداسازی سطح شرکت
**وضعیت: Accepted.** در شروع یک SQL Server database مشترک استفاده می‌شود. جداسازی منطقی در سطح Tenant و Company، مجوزدهی سمت سرور، فیلترهای دفاعی و تست‌های منفی اجباری است.

## DFT-005 — انتخاب شرکت و دوره مستقل از مدل حسابداری فرانو
**وضعیت: Accepted.** UX و رفتار قابل استفاده از صفحه انتخاب فرانو اقتباس می‌شود، اما مدل FiscalPeriod، migrationها و قواعد حسابداری آن منتقل نمی‌شوند. مدل دوره عملیاتی بازرگانی جداگانه طراحی می‌شود.

## DFT-006 — UX ورود و انتخاب
**وضعیت: Accepted.** فرم نام کاربری/گذرواژه، نمایش/مخفی‌سازی رمز، پیام‌های فارسی، انتخاب شرکت و دوره، وضعیت دوره‌ها و نمایش جزئیات دوره به‌عنوان صفحات پایه محصول حفظ و با API مستقل تطبیق داده می‌شوند.

## DFT-007 — لایسنس در فاز بعد
**وضعیت: Accepted.** اکنون قفل نرم‌افزار فعال نمی‌شود. فقط قرارداد و نقطه اتصال سروری پیش‌بینی می‌شود. کلید خصوصی صادرکننده در Git یا نصب مشتری قرار نمی‌گیرد. TPM اولویت آینده است؛ CNG نرم‌افزاری + DPAPI فقط با تأیید صریح و سطح اطمینان پایین‌تر.

## DFT-008 — RTL و دارایی محلی
**وضعیت: Accepted.** تمام صفحات فارسی RTL و وابستگی‌های CSS/JS/font/icon محلی و قابل انتشار آفلاین هستند.

## DFT-009 — عدم انتخاب خودکار شرکت/دوره قبلی
**وضعیت: Accepted.** سیستم شرکت یا دوره قبلی را بی‌درخواست کاربر فعال نمی‌کند. انتخاب فعلی هر نشست باید سروری اعتبارسنجی شود.

## DFT-010 — منبع نیازمندی
**وضعیت: Accepted.** پروپوزال نسخه ۱.۱ منبع دامنه است. تصمیم‌های جدید باید با منشأ و وضعیت مشخص شوند؛ خلأهای پروپوزال نباید با حدس به الزام قطعی تبدیل شوند.
