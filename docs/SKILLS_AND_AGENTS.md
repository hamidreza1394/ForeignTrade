# کیت مهارت‌ها و عامل‌ها

## مهارت‌های مخزن
- `.agents/skills/foreigntrade-engineering/SKILL.md`: گردش کلی مهندسی و مرزهای دامنه.
- `.claude/skills/api-design/SKILL.md`: طراحی API.
- `.claude/skills/react-patterns/SKILL.md`: React/TypeScript و RTL.
- `.claude/skills/security-multitenancy/SKILL.md`: جداسازی داده و مجوزدهی.
- `.claude/skills/dotnet-efcore/SKILL.md`: .NET و EF Core.
- `.claude/skills/testing-quality/SKILL.md`: تست و کیفیت.
- `.claude/skills/ui-ux-rtl/SKILL.md`: UX و دسترس‌پذیری فارسی RTL.

## عامل‌ها
معماری، Backend، Frontend، امنیت، تست/QA، بازبینی کد و مستندسازی در `.claude/agents/` تعریف می‌شوند.

## ابزارهای مورد انتظار
- .NET SDK و dotnet format/test
- SQL Server و ابزار EF Core
- Node.js/npm، Vite، TypeScript، Vitest و Playwright
- GitHub Actions برای CI
- ابزار بررسی امنیت وابستگی و secret scanning
- ابزارهای مرورگر برای E2E، DOM، Console و Network
- shadcn/ui CLI فقط با نسخه lockشده و بازبینی diff

## مهارت‌های نصب‌شده ChatGPT/Codex
در محیط عامل از مهارت‌های موجود برای TDD، git workflow، context engineering، API design، frontend UI، code review، security و debugging استفاده شود. مهارت‌های نصب‌شده در محیط اجرا الزاماً بخشی از فایل‌های مخزن نیستند؛ این سند راهنمای فعال‌سازی آن‌هاست.
