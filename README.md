# ForeignTrade

سامانه مستقل مدیریت بازرگانی خارجی و عملیات واردات.

> وضعیت: اسکلت اولیه پروژه در حال آماده‌سازی است؛ قابلیت‌های ورود، انتخاب شرکت/دوره و فرایندهای بازرگانی تا زمان پیاده‌سازی و آزمون نباید عملیاتی فرض شوند.

## تصمیم‌های پایه
- مخزن و چرخه انتشار مستقل از Farano Accounting.
- پایگاه داده SQL Server مشترک برای شرکت‌ها با جداسازی دسترسی در سطح Tenant و Company.
- معماری آغازین Modular Monolith؛ بدون Microservices زودهنگام.
- رابط فارسی RTL با React، TypeScript، Vite، Tailwind CSS و shadcn/ui؛ Backend مبتنی بر ASP.NET Core و EF Core، مشروط به تثبیت نسخه‌ها در پروژه.
- احراز هویت، مجوزدهی و کنترل دوره فقط در سمت سرور مرجع نهایی هستند.
- قابلیت اتصال به سامانه لایسنس در آینده از طریق قرارداد مستقل طراحی می‌شود؛ در فاز فعلی قفل نرم‌افزار فعال نیست.
